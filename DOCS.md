## 🛠️ Checklists Utiles

### ✅ Avant de Coder
- [ ] Environnement Python activé (`source venv/bin/activate`)
- [ ] MySQL en cours d'exécution
- [ ] Flutter installé et à jour (`flutter doctor`)
- [ ] Branch créée (`git checkout -b feature/...`)
- [ ] Code formaté selon les standards

### ✅ Avant de Committer
- [ ] Tests exécutés localement (`python manage.py test`)
- [ ] Linter passé (`flake8` pour Python)
- [ ] Pas de fichiers secrets exposés
- [ ] Commit message descriptif et conventionnel
- [ ] PR description complète

### ✅ Avant de Déployer
- [ ] Tous les tests passent
- [ ] Coverage > 80%
- [ ] Documentation mise à jour
- [ ] Aucun hardcoded secret
- [ ] Variables d'environnement configurées
